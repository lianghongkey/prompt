## Project Overview

TypeDuck is a macOS input method (IME) for Chinese Pinyin input. It's built with Swift and uses SQLite databases for lexicon storage. The project consists of:

- **TypeDuck/** - Main macOS input method application (Swift/SwiftUI)
- **CoreIME/** - Core input method engine (Swift Package)
- **Preparing/** - Database preparation tool (Swift Package)
- **Python scripts** - Dictionary expansion and maintenance utilities

## Build Requirements

- macOS 15.0+
- Xcode 16.0+
- Python 3 (for dictionary scripts)

## Common Commands

### Build Database
The database must be built before building the app:
```bash
cd Preparing/
swift run -c release
```

### Build Application
Do NOT use "Run" in Xcode - only Build or Archive:
```bash
xcodebuild -project TypeDuck.xcodeproj -scheme TypeDuck -destination 'platform=macOS' build
```

### Full Rebuild
Use the provided script:
```bash
./rebuild.sh
```

### Install for Testing
```bash
# Copy built app to Input Methods folder
cp -R ~/Library/Developer/Xcode/DerivedData/TypeDuck-*/Build/Products/Debug/TypeDuck.app ~/Library/Input\ Methods/

# Quit running instance
osascript -e 'tell application id "hk.eduhk.inputmethod.TypeDuck" to quit'

# Launch
open ~/Library/Input\ Methods/TypeDuck.app
```

### View Logs
```bash
log stream --predicate 'subsystem == "hk.eduhk.inputmethod.TypeDuck"' --level debug
```

### Switch Character Standard
```bash
# Switch to Simplified
defaults write hk.eduhk.inputmethod.TypeDuck CharacterStandard -int 4

# Switch to Traditional
defaults write hk.eduhk.inputmethod.TypeDuck CharacterStandard -int 1

# Restart to apply
osascript -e 'tell application id "hk.eduhk.inputmethod.TypeDuck" to quit'
```

## Architecture

### Database System
The input method relies on SQLite databases generated by the Preparing tool:
- **pinyin.txt** (70MB) - Main lexicon source in `Preparing/Sources/Preparing/Resources/`
- **imedb.sqlite3** - Generated database bundled with CoreIME
- Database is loaded read-only at runtime via `Engine.database`

To update the lexicon:
1. Modify `Preparing/Sources/Preparing/Resources/pinyin.txt`
2. Run `cd Preparing && swift run -c release`
3. Rebuild the app

### Core Components

**CoreIME Package** (`CoreIME/Sources/CoreIME/`)
- `Engine.swift` - Database access and query engine
- `Pinyin.swift` - Pinyin parsing and validation
- `PinyinSegmentor.swift` - Segments pinyin input into valid syllables
- `FuzzyPinyin.swift` / `FuzzyPinyinExpander.swift` - Fuzzy pinyin matching (zh/z, ch/c, etc.)
- `Candidate.swift` - Candidate generation and ranking
- `Simplifier.swift` - Traditional/Simplified conversion

**TypeDuck App** (`TypeDuck/`)
- `TypeDuckInputController.swift` - Main IMK controller, handles input events
- `MotherBoard.swift` - Coordinates UI and input processing
- `CandidateWindow.swift` - Candidate selection panel
- `AppContext.swift` - Shared application state
- `Options.swift` - User preferences and settings
- `UserLexicon.swift` - User dictionary management and word creation

### Input Flow
1. User types pinyin → `TypeDuckInputController` receives keystrokes
2. Input buffered and segmented by `PinyinSegmentor`
3. `Engine` queries database for matching candidates
4. `FuzzyPinyinExpander` applies fuzzy matching rules if enabled
5. Candidates displayed in `CandidateWindow`
6. User selects candidate → text committed to application

### Python Dictionary Tools
Located in root and `Preparing/`:
- `generate_pinyin_final.py` - Final pinyin dictionary generation
- `create_comprehensive_pinyin.py` - Comprehensive dictionary creation
- `massive_dict_expansion.py` - Expands dictionary with phrases
- `clean_and_expand_dict.py` - Cleans and expands existing dictionary
- `add_common_phrases.py` - Adds common phrases to dictionary

These scripts process and expand the pinyin lexicon before database generation.

## Important Notes

- The app cannot be Run directly from Xcode - it must be Archived/Exported and placed in `/Library/Input Methods/`
- Always rebuild the database after modifying `pinyin.txt`
- The app bundle identifier is `hk.eduhk.inputmethod.TypeDuck`
- Database queries use the `pinyintable` table with `shortcut` column for lookups
- Fuzzy pinyin settings are stored in user defaults and affect candidate generation
